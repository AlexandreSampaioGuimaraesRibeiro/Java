## 📂 Project
 
### 🏆 Championship Manager
 
A console-based Java application to manage sports championships. It allows the creation of multiple independent championships, each with configurable teams.
 
- Currently set up for **10 teams** by default
- Fully **reconfigurable** to support any number of teams
- Pure console/terminal interaction (no GUI)
**How to run:**
 
```bash
javac Main.java
java Main
```
