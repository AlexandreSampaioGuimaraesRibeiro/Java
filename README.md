# Java Projects

A collection of Java projects developed to practice and apply core programming concepts, including OOP design, data structures, and console-based application logic.

## 🎯 About

This repository gathers standalone Java projects built independently, outside of any specific course. Each project is organized in its own folder.

## 🛠️ Technologies

- **Java**

## 📁 Structure

| Folder | Description |
|---|---|
| `ChampionshipManager/` | Console app to manage multiple sports championships with configurable teams (currently set up for 10 teams, fully reconfigurable) |

## 🚀 How to run

Each project is independent. To run one of them:

```bash
cd project-name
javac Main.java
java Main
```

*(adjust the class name if it differs, or run it directly through your IDE)*
